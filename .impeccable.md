## Design Context

### Users
People managing IPTV portals who need to connect sources quickly and choose the
right programme guide without dealing with technical database concepts.

### Brand Personality
Quiet, practical, flexible. The interface should feel trustworthy and easy to
scan, while keeping advanced source configuration available when needed.

### Aesthetic Direction
Preserve the existing shadcn-based light/dark interface, spacing, and component
patterns. Use right-side sheets for source creation and editing, and compact,
well-grouped selectors for configuration choices.

### Design Principles
- Make the default (the portal's own EPG) clear and effortless.
- Keep advanced choices discoverable without making the common path noisy.
- Reuse familiar portal/source patterns and icons for consistency.
- Treat credentials and URLs carefully in both presentation and storage.
