Watch your channels without the usual fuss.

Add your playlists, keep your favourites synced across devices, and find what you want to watch fast. PortalHop keeps channels from different sources in one clean view, whether you are on your phone, tablet, or computer.

## Run

Copy `.env.example` to `.env`, set `DATABASE_URL`, then start the app:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
